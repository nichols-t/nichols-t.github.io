About This Site

This site is still a work in progress.

This site is produced by a simple substitution.sh script that emplaces template pages into content pages. These static files are then served via GitHub pages.

HTML fragments are stored in a _templates folder, while "actual content" is stored in the _content folder. The content pages have lines like $HEADER that will be substitutded for the contents of one of the template files.

Design

The colors for this site are taken from Sanzo Wada's color combination #305.

The source code can be found on GitHub.
