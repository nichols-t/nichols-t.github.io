About This Site

This site is still a work in progress.

Design

  • The font is Atkinson Hyperlegible Next . I like both this font and the spirit behind its design.
  • The background texture is an SVG from HeroPatterns.com.

Workflow

This site is produced by a simple substitution.sh script that emplaces template pages into content pages. These static files are then served via GitHub pages.

HTML fragments are stored in a _templates folder, while "actual content" is stored in the _content folder. The content pages have lines like $HEADER that will be substituted for the contents of one of the template files.

I typically draft written content in Obsidian, where I keep all my life's notes.

The source code can be found on GitHub.
